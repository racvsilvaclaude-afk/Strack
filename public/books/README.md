# About this folder

This folder is here to match the project's planned structure, but the app
doesn't currently read from it. Right now you load the EPUB file straight
from your computer using the "Choose an EPUB file" button inside the app
itself — nothing needs to be copied into this folder for that to work.

It's reserved for a possible later change where the app serves the book
directly instead of asking you to pick a file each time. Nothing to do
here for the proof of concept.
